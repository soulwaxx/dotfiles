name: research
disable-model-invocation: true
description: Investigate a question against high-trust primary sources and capture the findings as a Markdown file in the repository. Use when the user wants a topic researched or documentation and API facts gathered.
---

Investigate the question directly with the available search, fetch, documentation, and source-reading tools.

Apply any constraints on scope, recency, or acceptable sources. Then:

1. Trace each claim to a primary source, such as official documentation, source code, a specification, or a first-party API.
2. Write the findings to one Markdown file and cite the source for each load-bearing claim.
3. Follow the repository's convention for research notes. If none exists, use `research.md` and report its path.
4. Re-read the finished brief. Mark unsupported claims plainly instead of inferring an answer from secondary sources.

A research brief with unchecked citations is still unverified.
